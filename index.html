Guia de Arquitetura, Banco de Dados & GitHub

1. Sugestões de Melhorias para o Portal

  • Integração com o VLibras: Adicionar o widget oficial em 3D do Governo Brasileiro (vlibras-plugin) com tradução automática em tempo real para a Língua Brasileira de Sinais.
  • Camada Híbrida de Áudio: Além da Web Speech API nativa, suportar faixas de voz humana gravadas em estúdio com audiodescrição e feed de podcast acessível.
  • Modo Easy-to-Read (Linguagem Simples): Decomposição intralinguística de textos densos com pictogramas ARASAAC para pessoas com deficiência intelectual, afasia ou baixa alfabetização.
  • Selo de Homologação com PcD: Testes práticos com painel de pessoas cegas, surdas, com mobilidade reduzida e neurodivergentes antes de cada publicação de equipamento.

2. Estrutura de Banco de Dados Escalável (PostgreSQL / Supabase)

Schema relacional com integridade referencial, busca em português (Full-Text Search com GIN) e suporte a preferências de acessibilidade: 

-- 1. Usuários e Preferências de Acessibilidade
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    full_name VARCHAR(150) NOT NULL,
    role VARCHAR(30) DEFAULT 'reader', -- 'reader', 'admin'
    accessibility_prefs JSONB DEFAULT '{"fontSize": "base", "theme": "default", "dyslexiaFont": false}'::jsonb,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Notícias e Tecnologias Assistivas
CREATE TABLE articles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    title VARCHAR(300) NOT NULL,
    slug VARCHAR(320) UNIQUE NOT NULL,
    summary TEXT NOT NULL,
    content_markdown TEXT NOT NULL,
    category VARCHAR(50) NOT NULL, -- 'visual', 'auditiva', 'motora', 'cognitiva', 'fala'
    author_id UUID REFERENCES users(id),
    image_url TEXT NOT NULL,
    image_alt TEXT NOT NULL,
    audio_description TEXT NOT NULL,
    wcag_level VARCHAR(10) DEFAULT 'AAA',
    availability VARCHAR(50) DEFAULT 'Comercial',
    published_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Índice para Busca Textual em Português
CREATE INDEX idx_articles_search ON articles USING gin(
  to_tsvector('portuguese', title || ' ' || summary || ' ' || content_markdown)
);

3. Como Colocar no GitHub e Hospedar no GitHub Pages

Como este projeto está construído com HTML, CSS e JavaScript puros, você pode simplesmente enviar esses 3 arquivos para um repositório no GitHub: 

# 1. No terminal do seu computador:
git init
git add index.html style.css script.js
git commit -m "feat: Portal AcessiTech com HTML, CSS e JavaScript puros"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO/portal-acessitech.git
git push -u origin main

# 2. No GitHub:
# Acesse Settings > Pages > Source: "Deploy from a branch" > Branch: "main" / Root (/)
# O site estará no ar gratuitamente em seu-usuario.github.io/portal-acessitech/
